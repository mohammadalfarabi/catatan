# Semester I

## Pertemuan I
### Dasar Variable
1. Wadah untuk menampung/minyimpan nilai/data
2. Contoh
```python!
nama = "mas"
umur = 18
```
3. Aturan penamaan variable
- Harus di awali huruf (A-Z a-z) atau underscore 
- Hanya bisamengandung (A-z) (0-9) dan (_)
- Tidak boleh mengandung keyword Python

### type data
- String = untuk text/karakter
- Integer = untuk angka bilangan bulat
- Float = untuk angka desimal/pecahan
- Boolean = untuk 2 macam nilai saja True/False
- contoh
```python!
#string
nama = "mas"

#integer
umur = 18

#float
nilai = 99,99

#boolean
lulus = True
```

### operator
1. Operator Aritmatika
- (penjumlahan) +
- (pengurangan) -
- (perkalian) *
- (pembagian) /
- (modulus/sisa bagi) %
- (pangkat) **
- (bagi bulat) //
2. Operator Logika
- and
- or
- not
```python!
print(10+10)
print(10**2)
print(True and False)
print(not True)
```
### input dan output
```python!
#input
nama = input("Masukkan Nama anda = ")

#output
print(f"nama anda adalah {nama}")
```
